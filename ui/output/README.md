# `ui/output/` — generated boards

Boards generated by the UI land here and **are tracked**, so they can be shared
and reviewed without anyone having to re-run the pipeline.

## What is NOT tracked

`flux_*/` — the loose PNGs from each run. They are the same images the board
already embeds as base64, so tracking both stored every picture twice. The
boards render standalone; these are only for eyeballing an image without
opening Excalidraw.

## Mind the size

An `.excalidraw` board embeds every image as base64 inside the JSON, so a
6-image board is ~7 MB. Tracking them is a deliberate trade: easy sharing, at
the cost of repo weight. If this starts to hurt, the options are to prune old
boards, keep only exported PNGs, or move them to Git LFS.
