# pipeline

Planned home for the glue code that runs `modules/asr-diarization` -> `modules/kg-agent-memory` -> `modules/graphic-generation` end-to-end, validating each hop against the schemas in [`schemas/`](../schemas), and for the backend of an eventual unifying UI.

## Status

Not started. Each module currently runs standalone; this layer gets built once at least two modules are stable enough to wire together.
